\section{Introduction}
\label{sec:introduction}

\IEEEPARstart{A}{pproximate} computing exploits application error tolerance to improve hardware power, performance, and area (PPA) while preserving acceptable output quality~\cite{jiang2020approxarith,que2023approxsurvey,xu2016approxsurvey}.
For a domain-specific accelerator, these tradeoffs can be realized by replacing arithmetic units with appropriate approximate implementations drawn from component libraries~\cite{mrazek2017evoapprox,ullah2018smapproxlib,mrazek2019autoax}.
The design decisions include which arithmetic sites should remain exact, which should be approximated, and which implementation should be assigned to each approximated site.
These choices are coupled: local errors propagate through the computation, while logic synthesis and interactions along circuit paths determine the hardware cost of the complete design.
Consequently, selecting units solely from their individual error and cost characteristics does not establish the best accelerator-level PPA--quality tradeoff.

The number of possible assignments grows combinatorially with the number of configurable sites and available implementations.
In our evaluation, DCT and Laplace contain 76 and 60 configurable sites, with initial design spaces of approximately $3.26\times10^{91}$ and $1.77\times10^{72}$ configurations, respectively.
Exploring such spaces requires distinguishing promising designs without synthesizing and executing every candidate.
Yet the PPA and application quality needed to make these decisions are themselves expensive to obtain: logic synthesis evaluates hardware cost, and application execution measures the quality impact of the selected substitutions.
Efficient design space exploration (DSE) therefore depends on how these evaluations are conducted.

Surrogate models address this challenge by estimating hardware cost without running the complete hardware evaluation flow for every candidate.
Beyond approximate computing, learned models have been developed for high-level synthesis performance prediction~\cite{wu2022hls_gnn}, RTL-level area, power, and timing prediction~\cite{xu2022sns}, and early-stage power estimation for FPGA designs~\cite{lin2022powergear}.
These studies demonstrate the broader use of prediction models to reduce reliance on expensive synthesis and implementation evaluations.
For approximate accelerators, the models must additionally estimate how arithmetic substitutions affect application quality.
AutoAx~\cite{mrazek2019autoax} uses learned predictors to support automated exploration of approximate-component assignments.
ApproxPilot~\cite{zhang2025approxpilot} employs graph neural networks (GNNs) to model circuit topology and incorporates critical-path information into delay prediction.
ApproxGNN~\cite{vlcek2025approxgnn} learns reusable approximate-component representations and demonstrates transfer across related accelerator structures.
These approaches enable many candidate configurations to be explored through inexpensive predictions rather than repeated hardware evaluations.
However, obtaining accurate predictors can require substantial labeled data, collected either to train models for each target accelerator or to build a reusable pretrained model.
Although pretraining costs can be amortized across targets, constructing the underlying dataset still requires expensive evaluations. Target-specific training likewise incurs data-acquisition costs for the accelerator being optimized.
Performing this work offline does not remove its contribution to the overall design effort.

This motivates a different use of the evaluation budget. Basically, we may begin DSE with a limited labeled dataset and improve the models using measurements selected during exploration.
The challenge is that early models may contain prediction bias that distorts candidate rankings and the apparent Pareto front.
A promising predicted configuration may fail to deliver the expected PPA or output quality when evaluated, and repeatedly trusting such predictions can direct search toward misleading tradeoffs.
The framework must therefore support useful exploration before the surrogates are broadly accurate and obtain feedback that is relevant to subsequent optimization.

To this end, we present ApproxPilot-SE, a self-evolving DSE framework that combines measured-reference latency calibration with Pareto-guided evaluation and iterative surrogate training.
Starting from a limited set of measured configurations, configuration-aware GNNs predict accelerator PPA and application quality.
During search, the framework retrieves similar measured configurations and uses their prediction residuals to calibrate latency estimates.
This local correction anchors predictions to available measurements and can cancel a shared prediction-bias component when nearby configurations exhibit similar errors.
A path-aware readout supports the underlying latency model by preserving directed circuit dependencies without requiring explicit critical-path labels.

During DSE, Pareto-relevant candidates are selected for logic synthesis and application-quality evaluation.
These measurements establish the actual hardware cost and output quality of important candidate designs, reducing reliance on their predicted performance.
The evaluated configurations expand both the surrogate training dataset and the latency-calibration reference set.
The updated models and references then guide the next search round.
In this loop, search determines where new measurements are acquired, and the measurements reshape the predictions used by subsequent search.
Essentially, we co-evolve the surrogate learning and design exploration, and achieve the self-evolving DSE framework.

The main contributions of this work are summarized as follows:
\begin{itemize}
    \item We present a self-evolving framework, ApproxPilot-SE, for approximate accelerator DSE. It couples multiobjective search with Pareto-guided acquisition of measured configurations and iterative surrogate retraining. This process directs new training data toward optimization-relevant regions instead of relying exclusively on a model trained before exploration.

    \item ApproxPilot-SE retrieves nearby evaluated configurations and uses their prediction residuals to correct latency estimates without an additional learned correction model.
    Newly acquired measurements improve both the surrogate training set and the calibration reference set, while a path-aware readout provides structural support for latency prediction.

    \item With 720 training configurations per method, ApproxPilot-SE achieves the highest PPA hypervolume gain in 24 of 25 benchmark--quality settings.
    At 90\% structural similarity index (SSIM) retention, the geometric mean of its HV Gain ratios relative to the stronger baseline on each benchmark is 3.05.
\end{itemize}
