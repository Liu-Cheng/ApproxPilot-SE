
\section{Introduction}
\label{sec:introduction}

\IEEEPARstart{A}{pproximate} computing exploits the error tolerance of applications to trade off output quality against hardware cost~\cite{jiang2020approxarith,que2023approxsurvey,xu2016approxsurvey}.
For accelerators with multiple replaceable arithmetic units, combining approximate implementations at different locations creates a large number of candidate designs.
However, evaluating each candidate through logic synthesis and application-level accuracy evaluation is computationally expensive.
Prior studies therefore use surrogate models to replace many of these evaluations and improve the efficiency of approximate design space exploration (DSE).
AutoAx~\cite{mrazek2019autoax} uses machine learning to predict the hardware cost and output quality of candidate designs, treating an accelerator composed of approximate arithmetic units as a black-box function.
ApproxPilot~\cite{zhang2025approxpilot} introduces graph neural networks (GNNs) to improve prediction accuracy by modeling circuit topology and inferring critical-path information.
ApproxGNN~\cite{vlcek2025approxgnn} enables model transfer by learning representations of approximate components and demonstrates the reuse of pretrained models across image convolution filters.
These methods have substantially advanced surrogate-assisted approximate design.
Building reliable surrogates for target circuits without suitable pretrained models requires large numbers of ground-truth labels.
Constructing the training set of approximately 4,000 configurations for AutoAx required about 11 hours~\cite{mrazek2019autoax}.
ApproxPilot used 105,000 design samples for each of the Gaussian and KMeans benchmarks~\cite{zhang2025approxpilot}, while the initial ApproxGNN dataset contained 15,900 synthesized configurations~\cite{vlcek2025approxgnn}.
Efficient use of limited ground-truth evaluations is therefore essential for improving surrogate-assisted DSE.

With limited ground-truth labels, surrogate prediction errors can affect candidate ranking during multiobjective search.
Existing approximate-accelerator frameworks primarily use measured data for offline model training.
However, measurements obtained during DSE can provide additional information for subsequent optimization.
They can be used to update surrogate models and correct predictions using nearby evaluated configurations.
Combining these two mechanisms allows the search to benefit continuously from newly acquired measurements.

Building on this idea, we propose \textbf{ApproxPilot-SE}, a framework for optimizing approximate accelerators under a limited budget for ground-truth evaluations.
The framework first uses a limited set of evaluated designs to train surrogate models for power, performance, and area (PPA) and application accuracy.
It incorporates a path-aware readout to capture circuit dependencies for latency prediction.
During multiobjective DSE, ApproxPilot-SE calibrates latency predictions using nearby measured configurations.
It also periodically evaluates Pareto-relevant candidates and uses the resulting measurements to update the surrogates and guide subsequent search.
Finally, the Pareto front is constructed from synthesis results and application accuracy measurements.

The main contributions of this work are summarized as follows:

\begin{itemize}
    \item We develop ApproxPilot-SE, a framework that couples surrogate learning with multiobjective DSE through iterative ground-truth feedback.
    Pareto-relevant configurations are evaluated through logic synthesis and accuracy evaluation.
    The resulting data are used to update the surrogate models and guide subsequent search.

    \item We propose a local latency calibration method to improve latency prediction.
    The method uses nearby measured configurations to correct prediction errors and updates its calibration references as new measurements become available.
    A path-aware readout further captures circuit dependencies without requiring explicit critical-path labels.

    \item Our experimental evaluation on the DCT benchmark demonstrates the optimization performance and sample efficiency of ApproxPilot-SE.
    At 90\% SSIM retention, it achieves 3.79 times the PPA hypervolume gain of the stronger baseline with 720 training labels per method.
    With only 540 labels, it achieves 3.42 times the best baseline gain obtained with 900 labels, using 40\% fewer training labels.
\end{itemize}
